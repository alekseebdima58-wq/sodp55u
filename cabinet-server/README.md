# Синхронизация личного кабинета

Вкладка PWA показывает зачётку, приказы, учебный план, траекторию, профиль и состав группы. В состав группы входят имена. Приложение читает последнюю копию с отдельного HTTPS-сервера по персональному ключу. Сборщик открывает страницы кабинета в отдельном контексте Chromium для каждого студента.

## Подключение на сервере

Нужен Node.js 22 или новее. Выполняйте команды из папки `cabinet-server` под отдельным непривилегированным пользователем. `connect` и `reconnect` запускают видимый Chromium на сервере. Для этого потребуется доступ к его рабочему столу, например по защищённому каналу. Студент вводит пароль только в открывшемся окне на `newlk.samgups.ru`.

```sh
npm ci
npx playwright install chromium
node server.mjs connect
```

`connect` выдаёт идентификатор подключения и персональный ключ. Идентификатор используется для обслуживания подключения. Ключ студент вводит в PWA вместе с HTTPS-адресом сервера. Для каждого студента повторяется `connect` с отдельным входом.

```sh
CABINET_PWA_ORIGIN=https://alekseebdima58-wq.github.io node server.mjs serve
```

Проверьте origin фактического адреса PWA. Для своего домена замените пример. Несколько разрешённых origin можно перечислить через запятую. Сервис слушает `127.0.0.1:8776`. На HTTPS-прокси направьте `/cabinet/v1/snapshot` на этот адрес с сохранением заголовка `Authorization`. Запустите процесс через менеджер служб сервера. Интервал сбора по умолчанию 30 минут. Переменная `CABINET_SYNC_MINUTES` принимает значения от 5 до 1440.

Сессии и сохранённые данные находятся в `~/.local/state/sodp55u-cabinet`. Путь можно задать через `CABINET_STATE_DIR`. Папка должна оставаться вне репозитория и каталога раздачи файлов. Доступ к ней даёт доступ к сохранённым сессиям и студенческим данным. Используйте доверенный сервер и ограничьте доступ к рабочему столу, файлам и резервным копиям.

При истечении сессии PWA показывает последнюю копию и предлагает войти повторно. Команда `node server.mjs reconnect <идентификатор>` открывает новый вход в вуз и сохраняет прежний ключ PWA после проверки номера зачётной книжки. `node server.mjs disable <идентификатор>` отзывает ключ и удаляет сохранённую сессию и копию данных этого подключения. Кнопка «Отключить на этом устройстве» удаляет локальный ключ.

## Проверка

```sh
npm test
```

Тест использует две отдельные синтетические учётные записи, реальные экраны PWA и локальный сервер. В нём проверяются все шесть разделов, обновление по расписанию, изоляция ключей и данных, сохранение последней копии при истечении сессии и отзыв доступа.
