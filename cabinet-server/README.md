# Синхронизация личного кабинета

Во вкладке PWA студент вводит логин и пароль ПривГУПС. Сервер использует их для отправки обычной формы входа `newlk.samgups.ru/login` в отдельном контексте Chromium. После входа сохраняются cookie сессии, а в PWA — ключ доступа конкретного устройства. При повторном входе приложение проверяет, что открыта та же зачётная книжка. Дополнительные проверки, которые запрашивает сайт вуза, требуют обычного входа на сайте.

## Развёртывание

Нужен Node.js 22 или новее. Выполняйте команды из `cabinet-server` под отдельным непривилегированным пользователем.

```sh
npm ci
npx playwright install chromium
CABINET_PWA_ORIGIN=https://alekseebdima58-wq.github.io node server.mjs serve
```

Укажите фактический origin PWA, включая схему и без пути. Несколько разрешённых origin можно перечислить через запятую. Сервис слушает `127.0.0.1:8776`. Через доверенный HTTPS-прокси направьте `/cabinet/v1/login` и `/cabinet/v1/snapshot` на этот адрес. Передавайте заголовки `Origin` и `Authorization`. Не записывайте тела запросов, заголовки `Authorization` и трассировки браузерного входа в журналы прокси или приложения.

В `cabinet-config.json` в корне PWA укажите публичный HTTPS-адрес этого сервиса в поле `server`. Оставьте адрес пустым до развёртывания. Интервал синхронизации по умолчанию 30 минут. `CABINET_SYNC_MINUTES` принимает значения 5–1440. После подключения сервер сразу ставит кабинет в очередь на первое обновление.

Сессии и сохранённые данные находятся в `~/.local/state/sodp55u-cabinet`. Путь можно задать через `CABINET_STATE_DIR`. Храните каталог вне репозитория и раздачи статических файлов. Доступ к нему даёт доступ к сохранённым сессиям и студенческим данным.

Когда сессия истекает, PWA показывает последнюю копию и кнопку «Войти снова». Студент повторно вводит логин и пароль. Кнопка «Отключить» удаляет локальный ключ. Для отзыва ключа и удаления его сохранённой сессии и данных на сервере используйте `node server.mjs disable <идентификатор>`.

## Проверка

```sh
npm test
```

Сквозной тест использует синтетические учётные записи и макет портала. Он проверяет обычный вход, неверный пароль, дополнительную проверку, повторный вход, изоляцию данных двух студентов и обновление всех разделов в PWA.
